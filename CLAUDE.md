# census-postgres-scripts

Numbered shell/SQL scripts that download Census releases and load them into the Census Reporter PostgreSQL/PostGIS database.
They're written to run **on an Ubuntu EC2 instance** (paths like `/home/ubuntu/data/...`), not locally.
For the whole-system map see `../censusreporter/CLAUDE.md`. For the step-by-step runbook see `../census-api/DATA_UPDATES.md`.

## Layout
- Top level: legacy scripts for older releases (sequence-based ACS ≤2021, TIGER ≤2021, 2010/2020 blocks, PL94). They're kept for history.
  `README.md` describes a 2014-era from-scratch EC2 setup and is outdated.
- **`table_based/`: the current scripts.** Each new release is made by copying the previous year's script and find/replacing the year:
  - `02_download_acs_YYYY_{1,5}yr.sh`: curls the table-based summary file zip, `GeosYYYYNYR.txt`, and table shells. Downloads come from a
    `census-backup.b-cdn.net` mirror of www2.census.gov.
  - `03_import_acs_YYYY_{1,5}yr.sh`: needs `$PGURI`. It clones census-postgres, drops and recreates the schema, runs `create_geoheader.sql`/`create_tables.sql`,
    fixes geoids, `COPY`s each `acs*.csv` into `<table>_moe` (skipping `b98*`/`b99*` quality tables), then `create_views.sql`.
    It finishes by running `meta-scripts/fix_jam_values.py` as a backstop against sentinel values.
    Watch for embedded year formats like `20245` as well as `2024_5yr`.
  - `12_download_tiger_YYYY.sh`, `13_import_tiger_YYYY.sh`, `13_index_tiger_YYYY.sql` (builds `census_name_lookup`/`census_geo_containment`),
    `14_aiannh_tables_YYYY.sql`, `15_cbsa_geocontainment_YYYY.sql` (generated by `geocontainment_scripts/cbsa_containment.py`).
- Recent change: UAC and PUMA moved to their 2020 vintages (UAC20/PUMA20).

## Cautions
- The import scripts `DROP SCHEMA ... CASCADE`. Never run them against a database without explicit confirmation of the target `$PGURI`.
- TIGER errata recur (invalid geometries, missing CBSA/CSA/METDIV files, `varchar(0)` columns). DATA_UPDATES.md lists the known ones.
  When adding new errata, record them there.
